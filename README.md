# Learning HTML & Frontend Architecture

Welcome to my personal frontend development playground! This repository tracks my progression through 6 fundamental web projects, moving from basic semantic structures to fully responsive applications.

The core goal of this repository is to master document outlining, layout semantics, form validation, and clean stylesheet integration before moving on to advanced JavaScript application tiers.

---
Projects Page URL: https://roadmap.sh/projects/basic-html-website 

## 🚀 Projects Overview

### 📁 Project 1: Single-Page CV
* **Directory:** `Single-Page-CV`
* **Focus:** Foundation markup, typography hierarchy, document structuring, and basic lists.
* **Description:** A text-heavy resume layout designed to practice setting up standard headings (`<h1>` to `<h6>`), grouping text paragraphs, and managing layout flow accurately.

### 📁 Project 2: Multi-Page Structural Website
* **Directory:** `Basic-HTML-website`
* **Focus:** Page cross-linking, layout navigation, SEO metadata, and complex forms.
* **Description:** A multi-page mock portal consisting of a Homepage, Projects space, Articles log, and Contact page. It focuses on using semantic wrappers like `<nav>`, `<main>`, `<article>`, and `<fieldset>` tags without visual styling.

### 📁 Project 3: Visual Theme Stylesheets (CSS Basics)
* **Directory:** *[Upcoming]* `Styled-Core-Layouts`
* **Focus:** CSS selectors, box model, text manipulation, and color schemas.
* **Description:** Taking the barebone structural frameworks from previous exercises and mapping style sheets to manage color spaces, borders, padding, and type properties independently.

### 📁 Project 4: Interactive Interface Components
* **Directory:** *[Upcoming]* `Responsive-UI-Elements`
* **Focus:** Advanced CSS, Flexbox alignments, and structural grids.
* **Description:** Replicating dynamic layout segments—such as structured grid product grids and nested navigation drawers—focusing on fluid page distribution across variable viewport scales.

### 📁 Project 5: Responsive Web Layouts
* **Directory:** *[Upcoming]* `Responsive-Web-Layouts`
* **Focus:** Media queries, fluid typography, break-points, and flexible assets.
* **Description:** Building responsive, mobile-first design templates that adjust layouts seamlessly for micro-screens, tablets, and full desktop configurations.

### 📁 Project 6: Dynamic Frontend Integration
* **Directory:** *[Upcoming]* `Dynamic-Frontend-Integration`
* **Focus:** Layout templates, semantic routing strategies, and component reusability.
* **Description:** Consolidating global features (like persistent headers, footers, and sidebars) into standardized component configurations to manage scalable frontend projects efficiently.

---

## 🛠️ Core Technologies & Concepts Explored
* **Semantic HTML5:** Using meaningful containers (`<header>`, `<main>`, `<aside>`, `<footer>`) to construct readable document outline trees.
* **Form Architecture:** Building interactive inputs using strict labels, placeholder contexts, and required validation rules.
* **SEO Meta Optimization:** Tracking individual view attributes using unique meta description tags, viewport controls, and authorship metrics.
* **Version Control System:** Utilizing Git branches, tracking local file edits, and keeping repository histories organized.

## ⚙️ How to View Locally
1. Clone this repository to your computer:
   ```bash
   git clone https://github.com/shimmer-10/Learning-HTML.git
   ```
2. Navigate to any project directory (e.g., `Basic-HTML-website`).
3. Launch the entry point file (e.g., `index.html` or `home.html`) using a local development server like VS Code's Live Server extension.
